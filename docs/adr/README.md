# ADRs

Architecture decisions for warp-agent. The numbers are inherited from
warp-suite: the family's contract decisions stay there (the door protocol, the
`~/.warp` layout), so a gap in the series is expected and a new decision takes
the next free number in the family series (0013 after warp-suite's 0012).

Write one when a choice is hard to reverse and someone later will ask why. An
accepted ADR is not edited: supersede it with a new one that says so.
